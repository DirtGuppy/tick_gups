# Guppy Ticket System

by GupDirt.

## What is the project for?

Mac needs a system to help fix his disorganization and help structure his workflow.  What better way to do this than to create a ticket system, allowing a quick look at all the tasks that are needed to be started, continued, reviewed, as well as a quick look at what is completed.

## System in Summary

The ticket system will feature a couple of dictionaries for each stage of progress a feature/system is in.  Currently, the idea is to feature 4 stages for entries:  Not started, In-progress, review, and closed.  Entries can be pushed around between entries, but will only ever proceed to the next step, with the exception being the review step, which will allow one to push the item back into In-Progress.


Features:
Move:  ability to move a ticket to and fro dictionaries.  does NOT need to lock up shit.
Add:  Add ticket to project.  ticket will be assigned a random ass number for name, and user will assign a class of ticket (bug, feature, etc.) and a descriptor for the ticket.  optional: Time stamp.
Tag:  place a tag upon a ticket.  This will allow The users to see the relationship between various tickets.
